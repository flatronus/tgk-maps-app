# Кресленик речень

SVG/HTML/JS-застосунок, що перетворює введені користувачем речення на графічні схеми: кожне слово — прямокутник з текстом, прямокутники з'єднані лініями. Кожне графічне речення виводиться в новому рядку, не перекриває сусідні та відступає від них.

Застосунок є PWA (Progressive Web App) — його можна встановити на телефон чи комп'ютер, і він працює офлайн після першого відкриття.

## Файли застосунку

- `index.html` — головний файл застосунку (весь інтерфейс і логіка).
- `manifest.json` — маніфест PWA (назва, іконки, кольори).
- `sw.js` — service worker для офлайн-роботи.
- `icon-192.png`, `icon-512.png` — іконки застосунку.

## Як розмістити на GitHub Pages

1. Створіть новий репозиторій на GitHub (наприклад, `sentence-diagram`).
2. Завантажте туди всі файли зі списку вище одним рівнем (без вкладених папок): `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `README.md`.
3. У репозиторії відкрийте `Settings → Pages`.
4. У розділі «Build and deployment» оберіть `Source: Deploy from a branch`, гілку `main` (або `master`) і папку `/ (root)`, натисніть «Save».
5. Через 1–2 хвилини сайт стане доступним за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.
6. Відкрийте цю адресу в Chrome на телефоні чи комп'ютері — з'явиться можливість «Встановити застосунок» (Android/десктоп) або «Додати на головний екран» (iOS, через Safari → кнопка «Поділитись»).

Якщо після оновлення файлів у репозиторії зміни не з'являються на встановленому застосунку — це кешування service worker; підніміть номер версії в `sw.js` (змінна `CACHE_NAME`, наприклад `v1` → `v2`), закомітьте, і при наступному відкритті застосунок підвантажить свіжі файли.
